# Norway Internal Factors

Reserved for Norway factor candidates that may be useful internally before they earn public release.

Use this folder for:

- rough but official-source candidate harvests
- partial coverage tests
- semantics under review
- explicit internal bridge artifacts that are still too honest and awkward for a public surface
- investigated aggregation rules where the territory is visible but pooled votes still block a public-safe municipality split

Do not confuse this folder with public readiness.

Current internal-only artifacts include:

- `municipality_bridge_2021_to_current.csv`
- `territorial_haram_2021_partial_vote_share.csv`
- `territorial_haram_2021_partial_turnout.csv`
